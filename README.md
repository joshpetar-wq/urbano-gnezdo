# Урбано Гнездо Кривогаштани: веб-страна

Двојазична веб-страна (МК / EN) со админ панел. Вестите, проектите, настаните, галериите, документите, тимот, партнерите, бројките и сите текстови се менуваат од панелот, без код.

- Страна: `/mk` и `/en`
- Админ панел: `/admin`

## Објавување на Vercel (прв пат)

1. **Стави го кодот на GitHub.** Направи нов приватен репозиториум (на пр. `urbano-gnezdo-web`) и прикачи ја содржината на оваа папка. Најлесно е со GitHub Desktop или со „Add file → Upload files“ на github.com.
2. **Увези го во Vercel.** На vercel.com: *Add New → Project*, избери го репозиториумот и кликни *Deploy*. Ништо друго не треба да се менува.
3. **Поврзи складиште за содржината и сликите.** Во проектот на Vercel: *Storage → Create Database → Blob*. Избери пристап **Public** и кликни *Connect* на проектот. Vercel сам ја додава променливата `BLOB_READ_WRITE_TOKEN`.
4. **Постави лозинка за панелот.** *Settings → Environment Variables*, додај:
   - `ADMIN_PASSWORD`: лозинката со која ќе се најавувате во `/admin`
   - `SESSION_SECRET`: долг случаен текст (на пр. 40 произволни букви и бројки)
5. **Redeploy.** *Deployments → … → Redeploy*, за да се вчитаат новите поставки.
6. Отвори `https://твојот-проект.vercel.app/admin` и најави се.

## Свој домен

*Settings → Domains → Add*, внеси го доменот (на пр. `urbanognezdo.mk`). Vercel ќе ти ги покаже DNS-записите што треба да ги внесеш кај регистраторот на доменот. Откако ќе се поврзе, HTTPS се вклучува автоматски.

## Како се користи панелот

- **Содржина:** вести, проекти, настани, галерии, документи, тим, партнери, бројки. Секоја ставка има копчиња *Објави* и *Зачувај како нацрт*. Нацртите не се гледаат на страната.
- **Македонски / English:** горе во секоја форма. Ако вест, проект, настан, галерија или документ немаат англиски наслов, не се прикажуваат на англиската верзија. Кај тимот, партнерите и текстовите на страната, ако нема превод, се прикажува македонскиот текст.
- **Слики:** се намалуваат автоматски пред прикачување, па може директно од телефон.
- **Текстови и контакт:** главниот наслов, насловната фотографија (се прикажува во форма на крошна), „За нас“, мисија, визија, цели, контакт и социјални мрежи.
- **Пораки и пријави:** сè што луѓето ќе испратат преку контакт-формата и формата „Вклучи се“. Може да се преземат како CSV за Excel.

Секоја промена се гледа на страната веднаш по зачувувањето.

## Почетна содржина

Додека некој дел не се зачува првпат од панелот, страната ја прикажува почетната содржина од `src/lib/seed.ts`. Провери ги и смени ги:

- настанот „Отворена средба за нови членови“ е **пример** (измислен датум)
- описот на проектот „Урбано лето 2026“ е општ, дополни го
- датумот на веста за Локалниот младински совет
- е-пошта, телефон и социјални мрежи (сега се празни и не се прикажуваат)
- тимот е празен, додај ги членовите од *Тим*

## Работа на свој компјутер (опционално)

Потребен е Node.js 20 или понов.

```bash
npm install
npm run dev
```

Отвори http://localhost:3000. Без `BLOB_READ_WRITE_TOKEN`, содржината се чува во папката `.data`, а лозинката за `/admin` е `admin`.

## За програмери

- Next.js 16 (App Router), Tailwind CSS 4, Vercel Blob
- Моделот на содржината е во `src/lib/schema.ts`. Ново поле додадено таму автоматски се појавува во админ-формата и се зачувува.
- Секоја колекција се чува како еден JSON во Blob (`db/<клуч>/`), а секоја порака како посебен JSON (`messages/`).
- Јавните страници ја кешираат содржината (`unstable_cache`, ознака `content`), а секое зачувување од панелот го чисти кешот (`updateTag`).
- Пораките се чуваат на јавни Blob-адреси со случајни имиња што не се наведени никаде на страната.
